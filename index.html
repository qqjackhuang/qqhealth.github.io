亲情公寓小程序

给住在公寓里的长辈，和远在外面的子女，准备的一款温暖、字大、好用的协同工具。当前仓库已补齐可运行原型：微信原生小程序 + 可在网页里点的 H5 演示。

如何用微信开发者工具打开

  1. 安装并登录微信开发者工具。
  2. 选择「导入项目」，目录选仓库里的 miniprogram/。
  3. AppID 可先用测试号 / 游客模式 touristappid。
  4. 在「我的」里可切换「住户 / 家属」身份，体验两套视角。

下一步可以继续完善

  1. 申请微信小程序账号，换成正式 AppID，接入微信登录。
  2. 用云开发或自建 API 替换本地存储，让家属和住户看到同一份数据。
  3. 补真实支付、订阅消息、视频通话和健康设备上报。
